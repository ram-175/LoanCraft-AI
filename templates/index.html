ABOUT THE PROJECT

Machine Learning for Credit Risk Assessment

CreditAI is an academic prototype designed to demonstrate how Machine Learning can be applied to financial credit-risk classification. The system uses applicant characteristics such as financial information, loan amount, loan duration, and loan purpose.
